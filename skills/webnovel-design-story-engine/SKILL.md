# 故事引擎

把故事表达为可重复但可变化的循环：当前状态、人物行动、环境压力、事件、读者回报、状态变化和下一轮行动空间。

明确主角欲望、恐惧、价值优先级、行动机制、世界压力、状态维度、变化轴和长期线。人物必须有在压力下可解释的选择模式；不能用随机新敌人、等级膨胀或新增设定填补长期性。

候选类型只能是 `story_engine` 或 `character_state`。涉及主角核心动机、价值排序或不可逆设定时，返回待作者决策。

# 小说整体架构

本文件用于设计全书、卷、篇章、小篇章、章节和场景的嵌套商业结构。

不要模仿任何具体作者。这里使用的是成熟网络小说的通用技法：承诺递进、压力梯、信息差、反转、公开爽点和连载钩子。

## 核心思路

七步起承转合结构可以嵌套到每个层级：

- 全书。
- 卷或大地图。
- 篇章，通常 20-50 章。
- 小篇章，通常 3-10 章。
- 单章，通常 2500-3500 中文字。
- 场景，通常是一个冲突单元。

每一层都要有：

1. 主角优势亮相。
2. 反派或压力抬高。
3. 初次摩擦。
4. 信息差。
5. 反转。
6. 震惊效果。
7. 收获与下一个钩子。

层级越大，收获越大，下一个钩子也要更强。

## 全书架构

适用于 80 万-200 万字商业长篇。

```markdown
## 全书结构

读者承诺：
核心幻想：
开局劣势：
主角隐藏优势：
最终敌人/终极压力：
长线秘密：
最终地位变化：

全书七步：
1. 起/优势：主角独特设定进入世界。
2. 承/压力：社会秩序、家族、势力、世界规则或终极敌人建立压迫。
3. 承/摩擦：第一个局部冲突证明主角能赢一小块。
4. 转/信息差：世界低估主角，读者看见这个设定能持续放大。
5. 转/连续反转：主角不断破解更高层陷阱，同时付出代价。
6. 合/震惊：世界、势力或体系开始承认主角的价值或威胁。
7. 合/最终收获与新视野：主角完成地位跃迁，解决核心承诺，并视需要打开更大地图。
```

## 卷或地图架构

一卷通常代表新舞台：学校、城市、宗门、朝堂、战场、公司、末世基地、异世界或更高层地图。

```markdown
## 第X卷：标题
章节范围：
地图/舞台：
读者承诺：
新规则：
主要压力：
明面反派：
隐藏反派：
升级/资源目标：
秘密目标：
关系目标：
高潮：
出卷钩子：
```

每个新地图至少要抬高以下一项：

- 更强规则。
- 更强敌人。
- 更好资源。
- 更公开舞台。
- 更深秘密。
- 更高情绪代价。

## 篇章架构

篇章是主要回报单元，通常 20-50 章。

```markdown
## 篇章X：标题
章节范围：
核心承诺：
起始状态：
结束状态：
主要敌人：
敌人后台：
主角优势：
主要信息差：
小回报点：
中段反转：
篇章高潮：
公开震惊：
升级/资源收获：
秘密揭露：
关系变化：
下一篇章钩子：
```

篇章级七步：

1. 起：在新问题中展示主角优势。
2. 承：抬高敌人地位，说明主角为什么看起来会输。
3. 承：第一次交锋带来小胜或局部损失。
4. 转：敌人布局和公众怀疑拉高期待。
5. 转：主角靠核心设定反转，但要付出代价。
6. 合：公开或势力层面的震惊改变别人对主角的态度。
7. 合：主角获得地位、资源或线索，进入更大冲突。

## 小篇章架构

小篇章用于防止长篇章中段塌陷。通常 3-10 章。

示例：

- 医院假药小篇章。
- 训练资格小篇章。
- 公开切磋小篇章。
- 第一次裂隙清剿小篇章。
- 黑市线索小篇章。

```markdown
## 小篇章：标题
章节范围：
即时目标：
即时敌人/压力：
小优势：
陷阱/信息差：
反转：
奖励：
接入下一小篇章的钩子：
```

小篇章结尾通常给出：

- 新线索。
- 新敌人注意。
- 新资源。
- 新公众评价。
- 新伤势或代价。
- 新截止时间。

## 章节架构

单章使用 `seven-step-structure.md`。

每章都应该：

- 从压力、异常信息或即时选择开场。
- 早早展示主角优势。
- 抬高反派压力。
- 制造信息差。
- 至少打出一次反转。
- 写出具体人物反应。
- 用收获加下一场冲突结尾。

## 场景架构

场景不能只是聊天，必须改变某个状态。

场景形状：

1. 带着一个目标入场。
2. 碰到阻力。
3. 暴露筹码或隐藏事实。
4. 逼出选择。
5. 改变状态。
6. 留下残留物：线索、债务、伤势、怀疑、关系变化或新截止时间。

没有改变状态的场景，要删除或压缩。

## 升级梯

长篇要同时推进多条梯子：

- 战力梯：气血 -> 战技 -> 武者等级 -> 星门资格。
- 地位梯：被逼退考 -> 校内黑马 -> 江城前十 -> 武院观察对象 -> 特招候选。
- 敌人梯：学生反派 -> 教导主任 -> 贺家集团 -> 黑潮会外围 -> 武道署内鬼。
- 秘密梯：父亲污名 -> 周奎证词 -> 青岚07钥匙 -> 青岚残片 -> 事故记录 -> 内鬼。
- 资源梯：实战名额 -> 稳定剂 -> 战技训练 -> 裂隙资源 -> 镇渊名额。
- 关系梯：怀疑 -> 观察 -> 互利 -> 并肩 -> 信任 -> 队伍。

一章可以强推进一条梯子，轻推进一两条梯子。

## 回报节奏

商业连载可按这个节奏安排：

- 每章：一个钩子、一个冲突、一个阶段结果。
- 每 3-5 章：一个小回报或公开反转。
- 每 8-12 章：一次明显地位变化或敌人升级。
- 每 20-50 章：一次篇章高潮、资源收获、地图切换或重大秘密揭露。
- 每卷：一个新舞台和更高层敌人或规则。

## 设计检查

写长篇段落前，先检查：

```markdown
层级：
读者承诺：
当前主角优势：
当前反派压力：
信息差：
预期反转：
公开震惊对象：
收获：
下一钩子：
推进哪几条升级梯：
连续性风险：
```

如果一个段落缺少反派压力、信息差或收获，大概率会显得平。

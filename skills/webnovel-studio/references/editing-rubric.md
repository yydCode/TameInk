# 审稿评分标准

本文件用于按商业中文网络小说标准审稿。

## 评分维度

每项 0-10 分：

- 开篇钩子：是否立刻给读者继续看的理由。
- 主角目标：本章短期目标是否明确。
- 冲突密度：压力是否来得早，并逐步升级。
- 情绪回报：是否有爽点、痛点、甜点、惊点或有意义的损失。
- 节奏控制：说明、行动、对话、反应是否适合移动端阅读。
- 人物动机：人物选择是否自洽。
- 金手指规则：能力是否有边界、代价或不确定性，能否保留悬念。
- 章末钩子：结尾是否形成强烈的下一章问题。
- 平台适配：风格是否匹配目标平台和频道。
- 原创安全：是否避免近似复制已知作品、书名、人物和设定。
- 长篇连贯性：是否遵守事实库、时间线、战力规则和未解决线索。

综合评分不是简单平均。连载小说更重视开篇钩子、冲突、爽点、章末钩子和连贯性。

## 修改优先级

按这个顺序修：

1. 事实库矛盾。
2. 缺少钩子或主角目标不清。
3. 冲突弱、压力不足。
4. 爽点不清或没有章末钩子。
5. 人物动机问题。
6. 文字润色。

## 审稿语气

直接指出问题。不要空泛表扬。只有具体有效、应该保留的技法才值得表扬。

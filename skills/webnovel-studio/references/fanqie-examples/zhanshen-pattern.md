# 《我在精神病院学斩神》开篇结构拆解

> 用途：ChapterPlanner / DraftWriter 的反差人设开篇 few-shot 参考

## 作品元信息

- **书名**：《我在精神病院学斩神》
- **作者**：三九音域
- **平台**：番茄小说
- **题材**：都市异能 / 都市传说
- **核心卖点**：精神病院 = 斩神者培养基地的反差设定

## 开篇切入方式

### 首句技术

采用 **身份反差开篇**——主角以"病人"身份进入精神病院，但首句已埋下"病人不疯、医生可疑"的反转预期。

技术拆解：
1. **不写环境**：跳过院区描写、天气、时间
2. **不写内心独白**：直接用动作或对话切入
3. **第一句即冲突**：主角与"医生"或"病友"的第一次交锋
4. **信息差钩子**：读者比主角先察觉"医院不正常"

### 前 7 行铁律

| 行数 | 功能 | 技术要点 |
| --- | --- | --- |
| 1-2 | 切入场景 | 主角处于被处置位置（被收治/被诊断） |
| 3-4 | 反差信号 | 出现一处"医院不正常"的细节（不是恐怖，是违和） |
| 5-6 | 人物锚定 | 一个有名有姓的关键 NPC 立体亮相 |
| 7 | 钩子点燃 | 抛出第一个无法解释的疑点 |

### 首屏钩子类型

- **悬念型钩子**：医生/病友说出一句超出常理的话
- **反差型钩子**：主角发现"病人"的某项能力超出常人
- **威胁型钩子**：出现明确的死亡/被困风险

## 节奏密度

- **单章场景数**：1 个核心场景（病房内的对话/冲突）
- **信息密度**：每 200 字必有一个新信息点（设定 / 线索 / 反转）
- **场景边界**：不切场景，靠对话推进信息
- **爽点位置**：
  - 第 1 章末：主角展现"病人不疯"的第一次小爽
  - 第 3 章：揭示精神病院真相的部分片段
  - 第 10 章：主角第一次"斩神"行动

## 章末钩子

### 断章节点类型

1. **亮身份前断**：主角即将说出真实身份时断章
2. **反派行动前断**：反派即将对主角下手时断章
3. **悬念揭晓前断**：关键真相即将被揭开时断章

### 反面教材（禁止）

- ❌ 主角睡着 / 自然入睡收尾
- ❌ "这一夜过去"类时间跳跃收尾
- ❌ 主角思考人生意义的总结性收尾

## 可复用模板

### 反差人设开篇模板

```
[主角处于反差位置：被收治 / 被误判 / 被低估]
↓
[首句：动作或对话，不写环境]
↓
[3-4 行内：出现一个"违和细节"——不是恐怖，是逻辑不自洽]
↓
[5-6 行：关键 NPC 立体登场，有名字 + 一个动作 + 一句台词]
↓
[第 7 行：抛出第一个无法解释的疑点]
↓
[章末：在身份/真相/反派行动三个节点之一断章]
```

### 钩子强度校验

- 弱钩子：主角"感到一阵不安"——主观感受，无具体证据
- 中钩子：主角"发现病友的某项能力超出常人"——有具体证据
- 强钩子：医生"说出一句违反常理的话，且主角无法反驳"——有交互、有反差、有未解之谜

番茄平台铁律：第 1 章末必须是**强钩子**。

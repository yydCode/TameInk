# 番茄爆款黄金三章参考库

本目录收录番茄小说平台近年现象级作品的第 1 章结构拆解，作为 ChapterPlanner / DraftWriter 的 few-shot 参考。

每个文件遵循统一结构：
- **作品元信息**：书名 / 作者 / 平台 / 题材 / 上线时间（公开信息）
- **开篇切入方式**：首句/前 7 行/首屏钩子的具体技术拆解
- **节奏密度**：单章场景数、信息密度、爽点位置
- **章末钩子**：断章节点类型与悬念强度
- **可复用模板**：抽象成可注入的结构化模板（不包含原文复制）

## 使用约束

- 本目录是**结构化分析模板**，不是原文复制
- 引用片段仅用于技术分析（短于 50 字，明确标注出处）
- AI 生成时**禁止**逐字模仿原文，只允许借鉴结构骨架

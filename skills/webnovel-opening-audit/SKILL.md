# 开篇18元素审核

番茄开篇的合格标准是"结构化情节"而非文笔：必须在前 2-3 万字内完成
"冲突发生在主角身上 → 金手指展示 → 解决冲突"的完整闭环。

逐条核对 `skill.yaml` 中 `opening_audit_checklist` 的 18 项，对每一项给出：

- 通过 / 未通过；
- 未通过时，指出缺失了什么，并给出正文中最相关位置的引用证据；
- error 级项目缺失即为开篇硬伤，必须优先报告。

每条判断的 `evidence.reference` 必须逐字引用 `context_manifest` 中的正式来源或候选正文。
候选类型只能是 `evidence_finding`，属于 `hypothesis`，不能直接正式化。
不得输出收入预测、平台推荐判断或商业总分——只做结构化的开篇诊断。

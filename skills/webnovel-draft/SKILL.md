# 正文执行

把设定落在行动、选择、后果和具体反应中。遵守当前场景执行清单，推进已确认期待，保留下一行动空间；不写成设定说明书。

只处理作者已授权的范围。出现缺失关键事实、人物必须改变核心选择、计划与正式状态冲突时，返回 `needs_decision` 或 `conflict`，不要假设补齐。

候选类型只能是 `chapter_draft`。候选正文不得被描述为已发生事件，也不得自行更新人物、期待或记忆。

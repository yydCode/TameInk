# 实际回写

只依据本次明确给出的正式章节和已有正式状态，提取确实发生的事件、人物选择证据、关系变化、资源变化和期待兑现。明确区分新增、更新、关闭和不确定。

候选必须指出来源章节和精确位置。若正文不足以确认某项变化，保留为 `needs_decision` 或不输出，不推测补全。

候选类型只能是 `memory_proposal`、`actual_event`、`character_state` 或 `expectation`。所有结果都等待作者审批后才可写入正式层。

# 商业定位

1. 读取 `/skills/webnovel-studio/references/research-rules.md`。
2. 读取 `/skills/webnovel-studio/references/commercial-writing.md`。
3. 区分已知事实、作者假设和上线后才能验证的指标。
4. 输出明确的目标读者、核心欲望、差异化机制、开篇承诺和前三十章承诺。
5. 不把模型评分描述为真实收益预测。

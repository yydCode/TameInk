# 章节规划

1. 读取 `/skills/webnovel-studio/references/chapter-writing.md`。
2. 读取 `/skills/webnovel-studio/references/seven-step-structure.md`。
3. 本章必须有目标、冲突、情绪回报和章末钩子。
4. `context_intent` 只列出本章确实涉及、值得检索的词，不得堆砌无关实体。
5. 不改写已确认事实；发现冲突时在计划中明确暴露。
6. 番茄平台参考 `/skills/webnovel-studio/references/fanqie-examples/` 下的开篇结构拆解，借鉴结构骨架但禁止逐字模仿原文。

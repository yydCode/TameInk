# 留存审查

1. 读取 `/skills/webnovel-studio/references/editing-rubric.md`。
2. 读取 `/skills/webnovel-studio/references/commercial-writing.md`。
3. 七个基础维度分别给出整数分数和可证实理由。
4. 番茄平台额外评估四项专属维度：
   - `first_screen_hook`：前 7 行（手机一屏）钩子强度——是否有具体违和细节/动作，而非主观感受
   - `pacing_density`：节奏密度——无效环境铺垫与总结性解释占比越低分越高
   - `chapter_end_cliffhanger`：断章质量——是否卡在身份/真相/反派行动节点，禁止自然收尾
   - `character_contrast`：人设反差——主角与关键 NPC 是否有可被读者记住的反差锚点
5. 商业评分是编辑启发式，不是真实收益预测。
6. 问题引用必须唯一匹配候选正文。
7. 番茄专属维度参考 `/skills/webnovel-studio/references/fanqie-examples/` 下的结构拆解。
